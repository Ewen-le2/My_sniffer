# Changelog

All notable changes to this project will be documented in this file.

This project follows Semantic Versioning.

## [1.0.0] - 2026-10-09

First stable release of the cross-platform packet parser.

## Added
 - Cross-platform support for Linux and Windows.
 - CMake build system for building the project on supported platforms.
 - Ethernet frame parsing.
 - IPv4 packet parsing.
 - TCP and UDP protocol support.
 - Interactive command-line interface.
 - Command-line help menu.
 - Saved packet history.
 - Analysis alerts.
 - Interactive filter mode.
 - Protocol filtering by IPv4, TCP, and UDP.
 - Port filtering by source port, destination port, or either.
 - IPv4 address filtering by source address, destination address, or either.
 - MAC address filtering by source address, destination address, or either.

## Release
- Marked the project as version 1.0.0.
- Established the initial stable feature set.

## Info
The app is now stable enough to be used. The whole thing still has room for
improvement, with an interface and some features that need some fine-tuning.
Improvements will be made gradually, but this version is already functional.
